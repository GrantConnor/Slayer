Slayer Hub Alpha 1.9.8 — Electron build kit (Windows x64)
Install Node.js LTS, extract this ZIP, then double-click Build-and-Play.cmd.
The first build requires internet to download Electron. Afterward the Portable folder is self-contained; launch Slayer Hub.exe offline, without Node or Edge. Keep all files in Portable together. F11 toggles fullscreen. Resize using the window edges.
This is a build kit, not a prebuilt executable. Windows runtime has not been tested. Every tenth completed task gives 100 times current Slayer level XP; cancelled tasks do not count or reset the milestone counter. Milestone XP is not halved by auto combat.

Alpha 1.9.8: JSON saves every 30 seconds and on normal close. Saves are in %APPDATA%\Slayer Hub\saves\character.json with previous backup character.json.bak. Resume in hub. Ground loot and active enemies are not saved. Do not delete this folder when upgrading. Run Build-and-Play.cmd to update the portable app.
